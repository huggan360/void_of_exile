# Project style

Do not use middle-dot separators (U+00B7) or round-bullet glyphs (U+2022) in this project. The user explicitly forbids them. Use spacing, plain wording, or hyphens instead, including in UI labels, tooltips, previews, and documentation.

Keep UI artwork consistent with the game's pixel art. The shared font is Bree Serif, with heavier weights for headings and emphasis.
