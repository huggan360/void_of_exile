# Pet Yard art

Generated by `python3 tools/make_pets.py`. No prop or NPC registry is needed.
`manifest.json` records all folders, dimensions, voxel sizes, limbs and glow parts.
All models face local -Z, with Y up and their lowest occupied voxel at Y = 0.
`model.vox` is the assembled rest pose for editing; runtime loads the separate
parts so glow and articulation work.

## Creature models

Use `CreatureModel.new("pet_" + species)` for any of the fifteen species in
`docs/PETS.md`. Model heights match the Species table, including ears, horns,
sprouts and tendrils. Flight altitude and whole-body gait belong to PetFollower;
the rig has no extra hover or idle bob. Feet use `leg`, wings and fins use `wing`,
and tails, ears, gills and tendrils use `sway`. The rig's `gait` field is metadata.

The NPC folders are `creatures/caretaker/` and `creatures/pet_storekeeper/`, loaded
with `CreatureModel.new("caretaker")` and `CreatureModel.new("pet_storekeeper")`.
They use the town NPC body, arms and shared leg schema. The caretaker has a straw
hat, grey hair, apron and shoulder duck. The storekeeper carries a basket of eggs.

The separate `creatures/pet_egg/` model supports a hatching animation with
`CreatureModel.new("pet_egg")`. Its matching prop is `props/pets/pet_egg/`.
The transparent 64x64 item icon is `items/textures/pet_egg.png`, the path used by
`Item.icon()` for item id `pet_egg`.

## Yard props

Each folder contains `body.vox`, optional `body_glow.vox`, `rig.json`,
`building.json` and an editable `model.vox`, following `props/home/`.
Use `VillageHouse.new().setup({asset = "res://props/pets/" + id, pos = at,
yaw = angle, solid_size = Vector3.ZERO})` when the world owns collision.
`building.json` supplies suggested solid envelopes if needed; VillageHouse does
not read that file automatically. The bridge and small toys have no envelope.

opening is needed, rotate the gate's mesh holder around its left hinge.

## Validation and scratch previews

`python3 tools/make_pets.py --validate` checks the contract heights and gaits,
grounded rest poses, part references, combined model geometry, shared solid/glow
frames and the transparent icon. Add `--previews /tmp/voe_pet_art` for small
Python-rendered stills and contact sheets. Previews stay outside the project;
no Godot window is opened. Run the project's headless import after generating.

The actual runtime loaders and rig animation can be checked with
`~/Godot/godot_voxel_editor --headless --path . res://tools/make_pets_check.tscn`.
